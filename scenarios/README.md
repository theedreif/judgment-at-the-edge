# Scenarios

## Scenario Is the Product

A scenario is not decoration around content. It is the environment in which judgment becomes observable.

Useful scenarios create a gap between the expected plan and the conditions the learner actually encounters.

A Judgment at the Edge scenario should expose:

1. a meaningful **signal**;
2. changing or ambiguous **conditions**;
3. one or more operational **limits**;
4. a consequential **decision**;
5. observable **evidence** of the reasoning and result.

The purpose is not to trick the learner. The purpose is to make the decision visible.
