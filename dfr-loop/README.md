# DFR Decision Loop

> **NOTICE → INTEGRATE → PRIORITIZE → DECIDE → DEFEND**

A decision architecture for Drone as First Responder learning.

**NOTICE** — detect the meaningful signal.  
**INTEGRATE** — combine relevant information and context.  
**PRIORITIZE** — determine what matters now.  
**DECIDE** — select the justified action.  
**DEFEND** — explain the decision using evidence.
