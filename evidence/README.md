# Evidence

## Evidence Beats Completion

Completion tells us that a person reached the end of an experience.

Evidence tells us what the person noticed, decided, did, and learned.

Judgment becomes more useful when it can be examined without pretending uncertainty did not exist.

Evidence can include observed decisions, decision rationale, timing, escalation choices, system interactions, outcomes, and after-action updates.

The objective is not surveillance. It is a better answer to the question:

> **What evidence shows that this capability exists?**
